## 3. デザインシステム

`css/style.css` 冒頭の `:root` に集約。色はすべてトークン経由で指定し、直書きしない。

### カラー（ライト）
| トークン | 値 | 用途 |
|---|---|---|
| `--bg` | `#f5f8fb` | ページ背景 |
| `--surface` | `#ffffff` | カード・白帯 |
| `--ink` | `#13263d` | 本文 |
| `--muted` | `#55687c` | 補足テキスト |
| `--line` | `#d9e3ec` | 罫線 |
| `--navy` / `--navy-2` | `#0c2b4b` / `#123d66` | 紺帯（ヒーロー・営業資産・最終CTA・ヘッダー） |
| `--teal` / `--teal-strong` | `#0f8f84` / `#0b7a70` | アクセント・CTAボタン |
| `--teal-soft` | `#e2f4f1` | ハイライト背景 |
| `--l1`〜`--l4` | 紺→青→ティール | カリキュラムL1〜L4の色分け |

ダークモードは `@media (prefers-color-scheme: dark)` と `:root[data-theme="dark"]` の2か所で同じ値を再定義している（片方だけ変えないこと）。

**ツートン（2026-11-06〜）**：セクションごとに明るい背景（`.tone-l`）と紺の背景（`.tone-d`）を、2〜3個ずつ交互に並べている。ライト・ダークどちらのモードでも同じ見た目になる（色は `--lt-*` / `--dk-*` トークン）。クラスは中のトークン（`--bg` `--surface` `--ink` `--teal` `--l1`〜など）を差し替えるだけなので、部品側はトークンを使っていれば自動で明暗に対応する。
並び：ヒーロー（紺・画像）→ 課題（明・スキルシートの限界を統合）→ 営業資産（紺・画像）・3つの特徴（紺）→ カリキュラム（明）→ 休憩・工程（紺）→ 受講者記事・中間CTA（明）→ サポート（紺）→ 料金・導入の流れ（明）→ FAQ（紺）・最終CTA（紺・画像）→ フッター（明）

### タイポグラフィ（Google Fonts）
- 見出し：`--display` = Zen Kaku Gothic New（700 / 900）
- 本文：`--body` = Noto Sans JP（400 / 500 / 700）
- 数字：`--num` = Barlow（料金・時間・番号など。`tabular-nums`）

### その他
- 角丸は2種類のみ：`--r-sm: 6px` / `--r-lg: 14px`（ボタン・チップは999px）
- ブレークポイント：`860px`（2カラム→1カラム）、`480px`（スマホ微調整）
- 左右余白は `.wrap` で `max(16px, env(safe-area-inset-*))`。最大幅1120px
- 「AIっぽさ」回避方針：中央揃えは一部のみ、セクションごとに見せ方（チェックリスト／比較／帯／大数字／グラフ／タイムライン／写真）を変え、余白にメリハリをつけている

## 7. フォーム（スプレッドシート連携）

「資料をダウンロード」「無料で相談する」ボタン（`data-cta="doc"` / `data-cta="consult"`）を押すと、ページ内のモーダル（`<dialog id="contact">`）が開く。送信内容は Google Apps Script を経由して、スプレッドシートに1行ずつ追加される。

### 初回の設定（10分程度）
1. Google ドライブで新しいスプレッドシートを作る（例：「LP問い合わせ」）。共有設定は社内の担当者だけにする
2. スプレッドシートのメニュー「拡張機能 → Apps Script」を開く
3. 最初からある `コード.gs` の中身を消し、`gas/Code.gs` の中身をすべて貼り付けて保存する
   - 通知メールが欲しい場合は、`NOTIFY_TO` にメールアドレスを入れる
4. 関数 `testAppend` を選んで「実行」→ 権限の承認画面で許可する。スプレッドシートに「問い合わせ」シートとテスト行ができればOK（テスト行は消してよい）
5. 右上「デプロイ → 新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（LPの訪問者が送信できるようにするため。シートの中身は公開されない）
6. 表示された「ウェブアプリのURL」（`https://script.google.com/macros/s/…/exec`）を、`js/main.js` の `const ENDPOINT=''` に貼り付ける

### Code.gs を変更したとき
「デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン → デプロイ」で更新する。URLは変わらない。「新しいデプロイ」をするとURLが変わるので注意。

### 転記される列
受付日時／種別（資料請求・無料相談）／会社名／お名前／メールアドレス／電話番号／検討人数／ご相談内容／送信元ページ／対応状況（初期値「未対応」。営業が手で更新する）

### 仕様メモ
- 入力項目：資料請求は会社名・お名前・メール。無料相談は電話番号・検討人数（必須）とご相談内容（任意）が増える。モーダル内で種類を切り替えられる
- スパム対策：人には見えない入力欄（`website`）に値があれば保存しない。被害が続く場合は reCAPTCHA などを検討
- `=` `+` `-` `@` で始まる入力は、数式として実行されないよう先頭に `'` を付けて保存する
- `ENDPOINT` が空のまま送信すると、モーダル内に「送信先が設定されていません」と表示される
- JavaScript が動かない環境では、ボタンは従来どおり最終CTA（`#cta`）へのリンクとして動く

## 8. 受講者記事の自動表示（Zenn RSS）
- 取得元：`https://zenn.dev/p/ai_training_nbs/feed`（ZennのPublication「AI開発トレーニング」）
- 仕組み：ブラウザからZennのRSSは直接読めない（CORS）ため、フォームと同じ Apps Script の `doGet`（`?feed=zenn`）が中継し、JSONで返す。`js/main.js` が記事欄（`.articles[data-feed]`）を新しい順に差し替える
- 表示件数：`FEED_LIMIT`（3件）。載せない記事：`FEED_EXCLUDE`（記事URLに含まれる文字列）
- 反映のタイミング：Apps Script 側で3時間キャッシュする。新しい記事は最大3時間後にLPに出る
- 取得に失敗したとき（Apps Script 未更新・Zenn側の障害など）は、index.html に書いてある3件がそのまま表示される。記事が大きく入れ替わったら、この3件も書き換えておく
- 表示項目：サムネイル（ZennのOGP画像）・投稿日・執筆者名・タイトル。記事の説明文や技術タグはRSSに含まれないため表示しない
- 有効にする手順：`gas/Code.gs` を Apps Script に貼り直す → 関数 `testFeed` を選んで実行し、外部への接続を許可 → 「デプロイを管理 → 編集 → 新バージョン → デプロイ」（URLは変わらない）
